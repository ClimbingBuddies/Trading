# Decision Lab performance extension contract v1 — 7 October 2026

Additive prospective action trials; existing shared calls/reviews/outcomes and legacy Buy-to-Sell methodology remain immutable. Every original/review is one distinct AI event. Each event's trial begins at the close of the first verified session opening strictly after publication, with checkpoints 5 and 20 subsequent sessions. No fabricated or backdated events, missing sessions or fallback prices. Persist trusted observation/calendar identities and source values. Original event and model identity preserved.

Measure target equity allocation BUY/HOLD=100%, REDUCE=50%, WAIT/AVOID/SELL=0%; remaining cash earns zero. REDUCE is explicitly a standardized half-exposure trial, not the user's holding. Each checkpoint is a standalone hypothetical allocation from that event, not an actual portfolio or a duplicate independent trade. Paper action return includes 0.1% each side on its equity weight; stock and benchmark comparator returns include identical full-exposure costs. Compare against both full share exposure (opportunity cost) and pinned benchmark. A cash recommendation can outperform a falling share but lose against a rising benchmark. Preserve both results and avoid a fabricated win classification. Corporate-action changes/revisions block and are explicit; do not pretend dividends are accounted for. Existing paper cycle may retain its old sizing; label distinction.

Database-owned evaluator, no browser submissions. Function private.run_shared_action_evaluation_v1() is privileged, idempotent, only evaluates actual saved original/review events, no synthetic rows outside rollback. Called alongside existing runner. Same-event/checkpoint unique. Reject unsupported inputs; maintain per-event blockers and mature/pending counts. Public RPC public.shared_ai_performance_v1(p_scope text default 'all',p_horizon integer default 5) requires permanent signed-in user, watched via auth.uid/RLS; no accepted owner argument, no private note or owner identifiers. All cohort metrics over full scope, not list page.
