## Non-blocking advice

The live prepare function names its third argument `p_prompt_version` and persists it to `gpt_market_runs.prompt_version`, while the new specification currently calls the function with `independent-market-ai-v1`. During `OPS-002`, when the scheduled task is converted to a thin GitHub-spec runner, explicitly decide whether that value is intended to be the prompt/specification version, the methodology version, or whether the two should be stored separately. Do not silently treat those metadata concepts as interchangeable.

The prepare function is also `SECURITY DEFINER` in `public`; this audit does not treat that as a DOC-003 blocker because security hardening is explicitly scheduled in the later SEC phase, but it should be reviewed there.
