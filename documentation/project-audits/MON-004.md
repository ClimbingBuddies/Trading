### Security adviser review

Fresh Supabase Security Adviser output reports no alert-table RLS/grant defect. It does flag the two public shared classifier functions because they are `SECURITY DEFINER` and executable by `anon` / `authenticated`:

- `market_session_status_v1(text,timestamptz)`
- `market_freshness_status_v1(text,timestamptz,timestamptz,timestamptz)`

The functions were inspected directly. They have an empty search path, accept only caller-supplied classification inputs, return deterministic status text, do not expose privileged rows and do not mutate state. Their public executability is currently deliberate so the public Markets status view can use the private holiday/session helper. This does not fail MON-004, but the direct RPC surface should be narrowed if a clean alternative is introduced.

Supabase remediation references:

- https://supabase.com/docs/guides/database/database-linter?lint=0028_anon_security_definer_function_executable
- https://supabase.com/docs/guides/database/database-linter?lint=0029_authenticated_security_definer_function_executable

Other adviser findings are pre-existing/unrelated to MON-004, including the previously reviewed pg_net placement warning and general project advisories.

### Decision

**PASS WITH ADVICE.** The trigger lifecycle is independently proven to be persisted, owner-secured, idempotent, producer/schedule-driven and visible through the deployed Alerts workspace. The six approved source families, event history, rearm semantics, provenance, terminal telemetry and production behaviour satisfy the task Definition of Done and applicable Definition of Operational requirements.

### Non-blocking advice

1. Explicitly allow-list and browser-test `https://discoverbouldersmarkets.vercel.app/alerts` as an Auth redirect destination. The source requests that path, but this audit did not send a new magic-link email merely to generate redirect evidence. A valid production-origin permanent-user session is independently proven.
2. Prefer eliminating direct `anon` / `authenticated` RPC execution of the two `SECURITY DEFINER` freshness/session helpers if the shared public classifier can later be exposed without that surface. Until then, retain the empty search path and deterministic/no-row-access implementation.
